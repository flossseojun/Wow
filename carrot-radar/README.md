# 당근의 거짓말: 영국의 레이더 비밀

영어 본문(제2차 세계대전 영국의 레이더와 '당근 신화', 글의 순서 B → A → C)으로 고등학교 반 친구들에게 하는 3~5분 발표 자료입니다. 기계공학 진로에 맞춰 레이더 원리를 심화했습니다.

## 여는 법

`presentation.html`을 브라우저로 열면 됩니다. 인터넷 연결 없이 작동하는 파일 하나입니다.

| 키 | 동작 |
|---|---|
| → / Space / 클릭 | 다음 단계 |
| ← | 이전 단계 |
| N | 발표 대본 열기/닫기 (마지막 쪽에 예상 질문 포함) |
| F | 전체 화면 |

주소 끝에 `#static`을 붙이면 모든 단계가 펼쳐진 상태로 보입니다.

## 구성 (9쪽)

본문은 한 쪽으로 줄이고, 기계공학 진로와 연결한 심화를 중심에 두었습니다.

1. 질문 · 2. 본문 한눈에 (B → A → C 요약)
3. 반전 (포스터가 찢어지며 레이더 작전실로 전환)
4. 레이더 원리: 거리 = 속도 × 왕복 시간 ÷ 2
5. 회전 안테나와 4:1 감속 기어 (극좌표, 토크)
6. 바람의 힘: F = ½ρv²CA (풍속 2배 → 힘 4배)
7. 멈추는 거리: 반응 거리 + 제동 거리 v² ÷ (2μg)
8. 기계공학 지도: 동역학 · 유체역학 · 재료역학 · 제어공학
9. 마무리
