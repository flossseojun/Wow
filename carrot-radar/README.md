# 당근의 거짓말: 영국의 레이더 비밀

영어 본문(제2차 세계대전 영국의 레이더와 '당근 신화', 글의 순서 B → A → C)으로 고등학교 반 친구들에게 하는 3~5분 발표 자료입니다. 기계공학 진로에 맞춰 레이더 원리를 심화했습니다.

## 여는 법

`presentation.html`을 브라우저로 열면 됩니다. 인터넷 연결 없이 작동하는 파일 하나이고, 전자칠판처럼 키보드 없는 터치 화면에 맞춰 만들었습니다.

| 조작 | 동작 |
|---|---|
| 화면 누르기 | 다음 단계 |
| 옆으로 밀기 | 왼쪽으로 밀면 다음, 오른쪽으로 밀면 이전 |
| 오른쪽 아래 ‹ 이전 / 다음 › | 이전·다음 단계 |
| 오른쪽 위 전체 화면 / 대본 | 전체 화면 전환, 발표 대본 열기·닫기 |
| 레버 | 손가락으로 끌기 (레버를 눌러도 쪽이 넘어가지 않음) |
| 오른쪽 위 소리 켜짐/꺼짐 | 효과음 켜고 끄기 (설정은 브라우저에 기억됨) |

키보드가 있으면 → / Space / ←, N(대본), F(전체 화면)도 쓸 수 있습니다. 주소 끝에 `#static`을 붙이면 모든 단계가 펼쳐진 상태로 보입니다.

## 효과음

파일 안에서 직접 만들어 내는 소리라 인터넷이 없어도 납니다. 브라우저 규칙상 화면을 한 번 누른 뒤부터 소리가 납니다.

- 쪽 넘김: 포스터 쪽은 종이 넘기는 소리, 작전실 쪽은 짧은 전자음
- 같은 쪽 안 단계: 작은 딸깍 소리, 질문 카드 정답 공개: 세 음 올라가는 소리
- 3쪽 반전: 포스터가 찢어지는 소리
- 4·5쪽: 신호가 돌아올 때 레이더 핑
- 7쪽: 멈추면 성공음, 부딪히면 경고음 두 번

## 구성 (8쪽)

1. 질문 · 2. 본문 한눈에 (B → A → C 요약)
3. 반전 (포스터가 찢어지며 레이더 작전실로 전환)
4. 레이더 원리: 거리 = 속도 × 왕복 시간 ÷ 2
5. 안테나가 도는 모습: 탑 위 안테나가 돌며 하늘을 훑고, 비행기 쪽을 볼 때만 신호가 돌아옴
6. 회전 안테나와 4:1 감속 기어 (극좌표, 토크)
7. 레이더는 얼마나 멀리 봐야 할까: 레이더 감지 거리 ≥ 멈추는 거리
8. 마무리
